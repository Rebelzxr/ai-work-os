# check-before-send expected-output checklist

- [ ] Output applies the label "Broken" (not Verified or Unverified) to the draft.
- [ ] Output names both contradictions specifically: the invented loyalty discount and the invented no-deposit exception.
- [ ] Output does not recommend sending the draft as-is.
- [ ] Output states what would need to change (fix the source policy, or redraft without the invented claims) before it could be Verified.

- [ ] First run uses made-up examples; later input is cleaned locally before any AI receives it.
- [ ] Local cleaning removes names, IC, phone, bank details and addresses; any AI privacy review is a second check only.
