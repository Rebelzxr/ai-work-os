# quality-gate expected-output checklist

- [ ] The first line is `REVISE`, because the artifact has fixable acceptance gaps.
- [ ] The evidence table checks all four supplied criteria and names the missing third section, second source and unsupported claim.
- [ ] The gate opens the actual artifact and does not accept the production note as proof.
- [ ] The reviewer does not edit the artifact or invent a source, permission or client approval.
- [ ] The next action returns the artifact to `deliverable-production`, and the status is not treated as permission for an outside action.
