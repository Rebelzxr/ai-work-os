# stochastic-multi-agent-consensus expected-output checklist

- [ ] Output names "add a new tier" as the consensus (majority, independent).
- [ ] Output names the divergence camps ("raise now" vs "wait a quarter") rather than just the top pick.
- [ ] Output explicitly reports the outlier ("bundle instead") rather than dropping it.
- [ ] Output frames the result as a recommendation for the owner to decide on, not a decision already made.
