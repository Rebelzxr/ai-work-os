# feature-to-feeling expected-output checklist

- [ ] Rewritten opening line does not start with "Our platform" or similar third-person vendor framing.
- [ ] Rewritten line addresses the reader directly ("you"/"your").
- [ ] Output does not invent a benefit beyond what the two stated features (reminders, tracking dashboard) actually support.
- [ ] Output identifies the underlying feature it translated (traceable back to "automated reminders" or "payment tracking").
