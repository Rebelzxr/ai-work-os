# prompt-contract expected-output checklist

- [ ] Contract includes all five fields: GOAL, CONSTRAINTS, FORMAT, DONE WHEN, IF BLOCKED.
- [ ] DONE WHEN items are checkable (reference a concrete state), not "it looks good."
- [ ] CONSTRAINTS names something explicitly out of scope, not just a restatement of the goal.
- [ ] Output is not a plain restatement of "clean up the settings page" with no added specificity.
