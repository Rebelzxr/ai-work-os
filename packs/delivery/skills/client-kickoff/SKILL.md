# Client kickoff

This job turns an agreed scope into a clean start. It does not expand the promise or hide missing inputs.

## Start safely

Use an invented Malaysian business, invented project label and invented scope on the first run. Label the result **practice, not for use**. Do not ask for raw client messages, identity records, private contact details or unnecessary files.

For later work, use the approved scope, the owner-approved record of acceptance, the due window, the known source files and the acceptance criteria. Keep client facts labelled and minimum-necessary.

Clean project notes locally first. Remove names, identity numbers, phone numbers, bank details, addresses and raw private messages; keep originals outside the AI workspace and use labels. Do not ask the AI to clean an unclean record after upload.

## Steps

1. Compare the approved scope with the available inputs. Mark each item `ready`, `missing`, `unclear` or `outside scope`.
2. Group every missing item into one consolidated request with a reason, accepted format and latest useful date. Do not drip-feed separate requests for facts already known.
3. Turn the agreed work into milestones with an owner, a dependency and a check. Dates supplied by the owner stay exact; missing dates stay undecided.
4. Write the first production brief: objective, audience or use case, deliverable shape, source list, constraints, acceptance criteria and correction limit.
5. Record risks and unresolved decisions. An outside-scope request becomes a change decision, not an automatic addition.

## Output

Return a kickoff pack with: readiness table, one consolidated request, milestone table, first production brief, unresolved list and owner decisions. Mark any item without evidence as unverified. Do not call the project started, accepted or ready when a blocking input is missing.

## Failure modes

- Do not invent client approval, a deadline, source material, brand rules or access.
- Do not request more client data than the scope needs.
- Do not turn an extra request into included work.
- Do not present the consolidated request as delivered.

## Human approval

The owner checks the scope, data need, milestones and first brief. A person approves the exact client request and sends it through the chosen channel; this skill only prepares a local draft.
