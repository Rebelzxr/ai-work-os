# Deliverable production

This job creates the work product. The quality decision belongs to `quality-gate` in the default `aiwos-delivery` pack, which must inspect the result separately.

## Start safely

Use an invented Malaysian business, invented brief and small practice source set on the first run. Label the output **practice, not for use**. Do not ask for raw client records or private contact details.

For later work, use an approved scope, the first production brief, supplied source files, the target format and acceptance criteria. If a source is missing or a request is outside scope, record it before creating dependent work.

Clean project notes locally first. Remove names, identity numbers, phone numbers, bank details, addresses and raw private messages; use labels, keep originals outside the AI workspace and never ask the AI to clean an unclean record after upload.

## Steps

1. Restate the objective, deliverables, exclusions, source list, format and acceptance criteria in a short production header.
2. Check that the work can be made from the supplied sources. Mark missing, conflicting or unclear inputs in the unresolved list.
3. Create the deliverable in the requested local workspace format. Keep claims tied to a source or mark them as owner input.
4. Check the draft against each acceptance criterion and record evidence, not a self-awarded final status.
5. List unfinished items, owner questions, out-of-scope requests and any source or permission gap.
6. Hand the exact artifact, source list, unresolved list and acceptance checklist to the default `aiwos-delivery` pack's `quality-gate` skill. Do not merge production with the gate.

## Output

Return or save the artifact inside the workspace, plus a production note containing scope version, source list, changed files, unresolved items, criterion-by-criterion observations and the next `quality-gate` action in the default `aiwos-delivery` pack. Use `draft` or `needs review`, never `final`, until the separate gate passes.

## Failure modes

- Do not invent a source, statistic, testimonial, review, result, permission or client decision.
- Do not add an out-of-scope request because it seems small.
- Do not hide an unresolved input behind a polished draft.
- Do not claim the deliverable passed, shipped or reached the client before `quality-gate` in the default `aiwos-delivery` pack and the owner's decision.

## Human approval

The owner checks the artifact, unresolved list and source permissions. A person decides whether a gated artifact may be shared, posted, published, deployed or otherwise released; this job only creates a local draft.
